# Vote CLI Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Cung cấp script terminal kiểm tra và gửi một lượt bình chọn bằng Chrome.

**Architecture:** Dùng `playwright-core` mở Chrome với hồ sơ riêng. Module biểu mẫu chọn sao bằng giao diện, theo dõi duy nhất một lần gửi; CLI quản lý trạng thái và báo cáo đã loại dữ liệu xác minh.

**Tech Stack:** Node.js >=22, Playwright Core 1.64.0, node:test.

**Spec:** `docs/superpowers/specs/2026-10-08-vote-cli.md`.

## Global Constraints

- Chrome đã cài; hồ sơ riêng cố định; không sao chép hồ sơ Chrome cá nhân.
- Thịnh Liệt 1098; 8 tiêu chí, mỗi tiêu chí 5 sao.
- Tối đa một lần gửi mỗi lần chạy, không tự thử lại khi lỗi.
- Không ghi CAPTCHA, cookie, header hoặc toàn bộ nội dung phản hồi.
- Chặn gửi lại 24 giờ sau thành công, hết lượt hoặc kết quả chưa rõ.

## Review Focus

- HTTP 500 có thể xuất hiện sau khi máy chủ đã nhận lượt: trả kết quả chưa rõ và không gửi lại.
- API trả mã `3` dù widget có token: báo CAPTCHA bị từ chối, không coi là thành công.
- Hết lượt trên giao diện: dừng trước nút gửi.
- CAPTCHA thiếu hoặc hết thời gian phản hồi: không tự tạo token hay lặp gửi.
- Biểu mẫu thay đổi hoặc trạng thái gửi trước đó bị gián đoạn: dừng thay vì đoán dữ liệu hay gửi trùng.
